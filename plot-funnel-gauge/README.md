# Funnel and gauge

A sales funnel and a gauge with colored ranges.

Built with the [`dataviz::plot`](https://docs.rs/dataviz/latest/dataviz/plot/) API.

<img src="./screenshots/funnel_gauge.png" alt="Funnel and gauge" width="800">

## Run

```sh
git clone https://github.com/dataviz-rs/dataviz-examples.git
cd dataviz-examples/plot-funnel-gauge
cargo run --release
```

Writes `funnel_gauge.png` and `funnel_gauge.svg` to the current directory. See
[`src/main.rs`](src/main.rs) for the code.
